資料怎麼來

網頁本身不連 API。資料由同資料夾的 fetch_tw_data.py 在你的電腦抓取，從多個來源交叉驗證後寫入 data/dashboard_data.js，這個頁面再直接讀取，所以不會遇到瀏覽器跨域（CORS）問題。

線上版：GitHub Actions 每個交易日台北 19:30（收盤後 6 小時）在雲端執行 fetch_tw_data.py，交叉驗證後更新資料並自動發布到這個網頁。你的持股資料只存在目前這個瀏覽器（localStorage），不會上傳到 GitHub。

  • 股價：證交所 / 櫃買中心（官方）↔ Yahoo Finance ↔ FinMind ↔ 官方 OpenAPI
  • 月營收：公開資訊觀測站（官方）↔ 官方 OpenAPI ↔ FinMind
  • 法人：證交所 T86 / 櫃買三大法人（官方）↔ FinMind
  • 存貨：Yahoo 財報時序 ↔ FinMind 資產負債表

線上版操作

  • 新增 / 移除股票：到 GitHub 儲存庫 → Actions → 「Update data & deploy」→ Run workflow，在 add 或 remove 欄位輸入代號（空白分隔）。
  • 立即更新：同上，不填任何欄位直接 Run workflow。
  • FinMind Token：Settings → Secrets and variables → Actions → FINMIND_TOKEN，可隨時新增或修改。
  • 持股資料換手機 / 電腦：用持股區的「匯出」「匯入」搬移。

常用指令（在資料夾內執行）

  • 手動抓取：python fetch_tw_data.py（Windows 可雙擊 run_fetch.bat）
  • 新增股票：python fetch_tw_data.py --add 2454 2330
  • 移除股票：python fetch_tw_data.py --remove 2454
  • 完整重抓：python fetch_tw_data.py --full
  • 建立排程：Windows 執行 setup_schedule_windows.ps1；macOS / Linux 執行 bash setup_schedule_mac_linux.sh
